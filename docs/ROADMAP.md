# Roadmap

The prioritized backlog that shaped this app has been implemented. This file now
records the current state and the few ideas deliberately left out.

## Shipped

- **Learning journey** — a guided path with "continue where you left off",
  active-recall self-tests on the study exercises, one-tap spaced-repetition
  review, a first-run level picker that seeds difficulty ordering, and the
  session planner promoted to a primary entry point.
- **Content** — a fretboard note-naming speed trainer, a chord-box library +
  one-minute chord-change trainer, a metronome-graded rhythm module, an expanded
  ear-training set (scales/modes, cadences, a configurable interval trainer,
  degree-by-ear), a circle-of-fifths trainer, alternate/custom tunings, and a
  mic "play it" play-along.
- **Visual clarity** — a modern chip-style fretboard that zooms to the active
  fret region, colorblind-safe root encoding, phone-friendly navigation, an AA
  contrast pass, and visual answer feedback (e.g. the circle-of-fifths wheel).
- **Quick wins** — JSON progress export/import, metronome tap-tempo +
  subdivisions + tempo auto-ramp, and a reusable challenge mode (timer +
  question limit + personal best).

## Possible future ideas

- A short placement quiz to seed a starting level automatically (today the
  first-run picker sets the level manually).

## Explicitly out of scope

- **Full song / synced-tab library** — a different product (content, licensing,
  a tab engine). Middle-ground if ever desired: import-only Guitar Pro /
  MusicXML / ASCII tab into the existing fretboard viewer.
- **Full staff-notation reading** — needs a heavy notation library and drifts
  from the fretboard-first identity.
